# GitHub Pages Deployment

The repository includes `.github/workflows/deploy.yml`, which deploys the built Vite app to GitHub Pages on pushes to `main`.

If Pages is not already configured for GitHub Actions:

1. Go to the repository Settings.
2. Open Pages.
3. Under Build and deployment, choose GitHub Actions.
4. Push to `main`.
5. Wait for the deploy workflow to finish.
6. Open `https://meledddy.github.io/proxy/`.
